## LMS Integrations

### Supported Platforms

| Platform | Integration | Features |
|----------|-------------|----------|
| Canvas | LTI 1.3 | Launch, grade passback, roster sync |
| Moodle | LTI 1.3 | Launch, grade passback, completion |
| Blackboard | LTI 1.3 | Launch, grade passback |
| D2L Brightspace | LTI 1.3 | Launch, grade passback |
| SCORM | 1.2, 2004 | Package export, completion tracking |

### Key Features

- **Single Sign-On**: Students launch from LMS without separate login
- **Grade Passback**: Scores automatically sync to LMS gradebook
- **Deep Linking**: Create assignments directly from Wovser.AI
- **Roster Sync**: Import enrolled users automatically

## Webhooks

Receive real-time notifications:

```json
{
  "event": "session.completed",
  "data": {
    "sessionId": "sess_abc123",
    "quizId": "quiz_xyz789",
    "participantCount": 25,
    "averageScore": 82.5
  },
  "timestamp": "2025-12-29T10:30:00Z"
}
```

### Available Events

| Event | Description |
|-------|-------------|
| `session.started` | Quiz/assessment session began |
| `session.completed` | Session ended |
| `attempt.submitted` | Individual submission |
| `user.created` | New user registered |
| `user.deactivated` | User was deactivated |
