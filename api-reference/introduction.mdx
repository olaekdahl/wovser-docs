The Wovser.AI API allows you to programmatically create content, manage sessions, and retrieve analytics.

## Base URL

```
https://api.wovser.ai
```

For development/testing:
```
http://localhost:4000
```

## Authentication

All API requests require authentication using a Bearer token.

### Getting an API Token

1. Log into your Wovser.AI dashboard
2. Go to **Settings** → **API Keys**
3. Click **Generate New Key**
4. Copy and securely store the key

<Warning>
API keys grant full access to your account. Never share them or commit them to version control.
</Warning>

### Using the Token

Include the token in the `Authorization` header:

```bash
curl -X GET "https://api.wovser.ai/api/quizzes" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Response Format

All responses are JSON:

```json
{
  "data": { ... },
  "meta": {
    "timestamp": "2025-12-29T10:30:00Z"
  }
}
```

### Error Responses

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request parameters",
    "details": [
      {
        "field": "title",
        "message": "Title is required"
      }
    ]
  }
}
```

| HTTP Status | Meaning |
|-------------|---------|
| 200 | Success |
| 201 | Created |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 429 | Rate Limited |
| 500 | Server Error |

## Quick Start

### List Your Quizzes

<CodeGroup>
```bash cURL
curl -X GET "https://api.wovser.ai/api/quizzes" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch('https://api.wovser.ai/api/quizzes', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});
const quizzes = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.wovser.ai/api/quizzes',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)
quizzes = response.json()
```
</CodeGroup>

### Create a Quiz

<CodeGroup>
```bash cURL
curl -X POST "https://api.wovser.ai/api/quizzes" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "JavaScript Basics",
    "projectId": "proj_abc123",
    "questions": [
      {
        "prompt": "What is the typeof null?",
        "options": [
          {"label": "null", "isCorrect": false},
          {"label": "object", "isCorrect": true},
          {"label": "undefined", "isCorrect": false},
          {"label": "number", "isCorrect": false}
        ]
      }
    ]
  }'
```
</CodeGroup>
