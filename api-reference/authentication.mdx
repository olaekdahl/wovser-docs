## Overview

The Wovser.AI API uses Bearer token authentication. You must include a valid API key in every request.

## Getting API Keys

### Generate a Key

<Steps>
  <Step title="Log In">
    Sign into your Wovser.AI account at [app.wovser.ai](https://app.wovser.ai)
  </Step>
  
  <Step title="Navigate to Settings">
    Click your profile → **Settings** → **API Keys**
  </Step>
  
  <Step title="Create Key">
    Click **Generate New Key**
    
    Configure:
    - **Name**: Descriptive name (e.g., "CI/CD Pipeline")
    - **Scopes**: Select permissions (or leave all for full access)
    - **Expiration**: Optional expiry date
  </Step>
  
  <Step title="Copy Key">
    Copy the key immediately. It won't be shown again!
    
    <Warning>
    Store API keys securely. Never commit them to git or share publicly.
    </Warning>
  </Step>
</Steps>

### Key Scopes

| Scope | Access |
|-------|--------|
| `quizzes:read` | List and get quizzes |
| `quizzes:write` | Create, update, delete quizzes |
| `assessments:read` | List and get assessments |
| `assessments:write` | Create, update, delete assessments |
| `challenges:read` | List and get code challenges |
| `challenges:write` | Create, update, delete challenges |
| `sessions:read` | View session data |
| `sessions:write` | Start and manage sessions |
| `analytics:read` | Access analytics data |

## Using API Keys

### Bearer Token

Include the API key in the `Authorization` header:

```bash
Authorization: Bearer wvsr_live_abc123...
```

### Full Example

<CodeGroup>
```bash cURL
curl -X GET "https://api.wovser.ai/api/quizzes" \
  -H "Authorization: Bearer wvsr_live_abc123xyz789"
```

```javascript JavaScript
const response = await fetch('https://api.wovser.ai/api/quizzes', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer wvsr_live_abc123xyz789',
    'Content-Type': 'application/json'
  }
});
```

```python Python
import requests

response = requests.get(
    'https://api.wovser.ai/api/quizzes',
    headers={
        'Authorization': 'Bearer wvsr_live_abc123xyz789'
    }
)
```

```typescript TypeScript
const response = await fetch('https://api.wovser.ai/api/quizzes', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.WOVSER_API_KEY}`,
    'Content-Type': 'application/json'
  }
});
```
</CodeGroup>

## Key Types

### Live Keys

- Prefix: `wvsr_live_`
- Used in production
- All operations are real
- Counts against billing

### Test Keys

- Prefix: `wvsr_test_`
- Used for development
- Data is isolated
- No billing impact

<Info>
Test keys access a separate sandbox environment. Data created with test keys won't appear in your live account.
</Info>

## Security Best Practices

### Do ✅

- Store keys in environment variables
- Use secrets management (AWS Secrets Manager, Azure Key Vault)
- Rotate keys periodically
- Use minimum required scopes
- Set expiration dates

### Don't ❌

- Commit keys to version control
- Share keys in chat/email
- Use live keys in development
- Expose keys in client-side code
- Use a single key for everything

### Environment Variables

```bash
# .env (never commit!)
WOVSER_API_KEY=wvsr_live_abc123xyz789
```

```javascript
// Usage
const apiKey = process.env.WOVSER_API_KEY;
```

## Authentication Errors

### 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid or missing API key"
  }
}
```

Causes:
- Missing Authorization header
- Invalid API key
- Expired API key

### 403 Forbidden

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "Insufficient permissions for this operation"
  }
}
```

Causes:
- API key lacks required scope
- Accessing another tenant's data
- Feature not available on your plan

## Revoking Keys

To revoke a compromised key:

1. Go to **Settings** → **API Keys**
2. Find the key
3. Click **Revoke**
4. Confirm revocation

<Warning>
Revoked keys stop working immediately. Update your applications before revoking.
</Warning>
