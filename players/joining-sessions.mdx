## Join Methods

### Using a PIN Code

The most common way to join:

<Steps>
  <Step title="Go to Join Page">
    Visit [app.wovser.ai/join](https://app.wovser.ai/join)
  </Step>
  
  <Step title="Enter PIN">
    Type the **6-digit code** shown by your host
    
    <Frame>
      <img src="/images/players/enter-pin.png" alt="Enter PIN" />
    </Frame>
  </Step>
  
  <Step title="Enter Your Name">
    Choose a nickname or enter your real name
    
    <Info>
      Some sessions may require your real name or email.
    </Info>
  </Step>
  
  <Step title="Wait in Lobby">
    You'll see a waiting screen until the host starts.
  </Step>
</Steps>

### Using a Direct Link

If you receive a link:

1. Click the link (or paste in browser)
2. Sign in or enter your details if prompted
3. Click **Join** or **Start**

### Using a QR Code

1. Open your phone's camera
2. Point at the QR code
3. Tap the notification to open
4. Follow the prompts

### From an LMS (Canvas/Moodle)

If your organization uses an LMS:

1. Log into your LMS
2. Find the assignment
3. Click **Launch** or **Start**
4. You'll be automatically signed in

## Lobby Experience

Once you've joined:

- See other participants joining
- View session information
- Wait for host to start
- Check your connection status

<Info>
If you see your name in the participant list, you're connected!
</Info>

## Troubleshooting

<AccordionGroup>
  <Accordion title="PIN not working" icon="triangle-exclamation">
    - Double-check the code (6 digits)
    - Make sure the session hasn't ended
    - Ask host to confirm the PIN
    - Try refreshing the page
  </Accordion>
  
  <Accordion title="Can't connect" icon="wifi">
    - Check your internet connection
    - Try a different browser
    - Disable VPN if using one
    - Clear browser cache
  </Accordion>
  
  <Accordion title="Name rejected" icon="user-xmark">
    - Avoid special characters
    - Try a different nickname
    - Use your email if required
  </Accordion>
  
  <Accordion title="Stuck in lobby" icon="hourglass">
    - Wait for host to start
    - Don't refresh (you may lose your spot)
    - Check if session was postponed
  </Accordion>
</AccordionGroup>

## Late Joining

If a session has already started:

- **Late join enabled**: You can still enter with the PIN
- **Late join disabled**: Contact your host

<Warning>
If you join late, you may miss questions that have already been asked.
</Warning>
