## Quick Start

### Joining with a PIN

1. Go to [app.wovser.ai/join](https://app.wovser.ai/join)
2. Enter the **6-digit PIN** provided by your host
3. Enter your name or nickname
4. Wait in the lobby for the session to start

### Joining with a Link

1. Click the link shared by your host
2. Enter your email if required
3. Click **Start** when ready

## What to Expect

### Live Quizzes

Fast-paced, competitive fun:

- ⏱️ **Timed questions** - Answer quickly for bonus points
- 🏆 **Leaderboard** - See how you rank in real-time
- 🎯 **Instant feedback** - Know immediately if you're right
- 🎉 **Celebrations** - Podium finish for top scorers

### Assessments

Structured evaluations:

- 📝 **Multiple question types** - MCQ, short answer, essay
- ⏰ **Time limits** - Per question or total (varies)
- 🔄 **Review before submit** - Change answers before final submission
- 📊 **Results** - Score shown immediately or after review

### Code Challenges

Programming tasks:

- 💻 **VS Code environment** - Real IDE in your browser
- ▶️ **Run & test** - Execute your code against test cases
- 📋 **Problem statement** - Clear requirements and examples
- ✅ **Automatic scoring** - Based on passing tests

## Requirements

### Browser

| Browser | Minimum Version |
|---------|-----------------|
| Chrome | 90+ |
| Firefox | 88+ |
| Safari | 14+ |
| Edge | 90+ |

<Warning>
Internet Explorer is not supported.
</Warning>

### For Code Challenges

- Stable internet connection
- JavaScript enabled
- Pop-ups allowed (for workspace window)

### For Proctored Assessments

If proctoring is enabled:

- 📷 **Webcam** - Camera access required
- 🔊 **Microphone** - May be required
- 🖥️ **Single monitor** - Additional monitors may be flagged
- 🌐 **Stable connection** - Interruptions are recorded

## Tips for Success

<Tip>
**For live quizzes:**
- Read questions carefully but quickly
- Trust your first instinct
- Speed matters for tiebreakers
- Stay focused through all questions
</Tip>

<Tip>
**For assessments:**
- Read all instructions first
- Manage your time across questions
- Flag questions to return to
- Review before submitting
</Tip>

<Tip>
**For code challenges:**
- Read the problem statement completely
- Start with the examples
- Test your code before submitting
- Check edge cases
</Tip>
