### Scheduled Reports

Set up automatic report delivery:

1. Go to **Settings** → **Scheduled Reports**
2. Click **Create Report**
3. Configure:
   - Report type (summary, detailed, custom)
   - Frequency (daily, weekly, monthly)
   - Recipients (email addresses)
   - Format (PDF, CSV)
4. Save schedule

## API Access

Access analytics programmatically:

```bash
# Get session analytics
GET /api/sessions/{sessionId}/analytics

# Response
{
  "sessionId": "abc123",
  "totalParticipants": 50,
  "averageScore": 82.5,
  "passRate": 0.94,
  "questionStats": [...],
  "scoreDistribution": {...}
}
```

See [API Reference](/api-reference/introduction) for full documentation.
