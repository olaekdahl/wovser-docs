As a **Host** in Wovser.AI, you can create engaging learning experiences, run live sessions, and track participant performance.

## What Can Hosts Do?

  <Card title="Create Content" icon="plus">

  </Card>
  <Card title="Run Sessions" icon="play">

  </Card>
  <Card title="Monitor Progress" icon="eye">
    Watch real-time participation and scores
  </Card>
  <Card title="Analyze Results" icon="chart-bar">
    Review detailed analytics and export reports
  </Card>

## Content Types Comparison

| Feature | Quiz | Assessment | Code Challenge |
|---------|------|------------|----------------|
| **Best For** | Live events, training | Evaluations, certifications | Technical hiring |
| **Format** | Real-time, gamified | Self-paced or timed | IDE-based coding |
| **AI Generation** | ✅ Questions + answers | ✅ Questions + rubrics | ✅ Problems + tests |
| **Live Leaderboard** | ✅ | ❌ | ❌ |
| **Proctoring** | ❌ | ✅ Optional | ✅ Optional |
| **Auto-Scoring** | ✅ | ✅ | ✅ Test-based |
| **Code Execution** | ❌ | ❌ | ✅ Sandboxed |

## Host Dashboard

Your dashboard provides quick access to:

- **Recent Projects** - Jump back into your work
- **Active Sessions** - Monitor ongoing quizzes and assessments
- **Quick Stats** - Total participants, completion rates, average scores
- **Notifications** - Session completions, invitations, system updates
