Assessments are formal evaluations used for certifications, hiring, course completion, and skills verification. Unlike quizzes, assessments are typically self-paced and can include proctoring.

## Assessment vs Quiz

| Aspect | Quiz | Assessment |
|--------|------|------------|
| **Pacing** | Real-time, host-controlled | Self-paced or timed |
| **Competition** | Live leaderboard | Individual results |
| **Question Types** | Multiple choice | MCQ, open-ended, coding |
| **Proctoring** | No | Optional (webcam, behavior) |
| **Certificates** | Optional | Common |
| **Use Case** | Training, events | Hiring, certifications |

## Create an Assessment

<Steps>
  <Step title="Start Assessment Creation">
    Navigate to your project and click **Create New** → **Assessment**.
  </Step>
  
  <Step title="Configure Basic Settings">
    Set up your assessment:
    
    | Setting | Description |
    |---------|-------------|
    | **Title** | Name displayed to participants |
    | **Description** | Instructions and context |
    | **Time Limit** | Total time allowed (optional) |
    | **Passing Score** | Minimum percentage to pass |
    | **Attempts** | Number of allowed attempts |
  </Step>
  
  <Step title="Add Questions">
    <Tabs>
      <Tab title="AI Generation">
        Use a prompt to generate questions:
        
        ```
        Create a 20-question assessment for AWS Solutions Architect 
        certification prep. Include:
        - 10 multiple choice questions on core services
        - 5 scenario-based questions
        - 5 questions on best practices and architecture
        Difficulty: Intermediate to Advanced
        ```
      </Tab>
      <Tab title="Question Bank">
        Import from your organization's question bank:
        1. Click **Import from Bank**
        2. Filter by category, tags, difficulty
        3. Select questions
        4. Click **Add to Assessment**
      </Tab>
      <Tab title="Manual">
        Add questions one by one:
        1. Click **Add Question**
        2. Select question type
        3. Enter content and scoring
      </Tab>
    </Tabs>
  </Step>
  
  <Step title="Configure Sections (Optional)">
    Organize questions into sections:
    
    ```
    Assessment: AWS Solutions Architect
    ├── Section 1: Core Services (10 questions, 30 min)
    ├── Section 2: Architecture Scenarios (5 questions, 20 min)
    └── Section 3: Best Practices (5 questions, 10 min)
    ```
    
    <Info>
      Sections can have individual time limits and can be marked as required or optional.
    </Info>
  </Step>
  
  <Step title="Set Up Proctoring (Optional)">
    Enable proctoring for high-stakes assessments:
    
    <AccordionGroup>
      <Accordion title="Webcam Monitoring" icon="video">
        - Face detection to ensure single test-taker
        - Multiple person detection alerts
        - Frame capture for flagged events
      </Accordion>
      <Accordion title="Browser Lockdown" icon="lock">
        - Tab switch detection
        - Copy/paste monitoring
        - Fullscreen enforcement
      </Accordion>
      <Accordion title="ID Verification" icon="id-card">
        - Photo ID capture before start
        - Face comparison with ID photo
      </Accordion>
    </AccordionGroup>
    
    <Warning>
      Proctoring requires participant consent and camera/microphone permissions.
    </Warning>
  </Step>
  
  <Step title="Configure Completion Settings">
    Set what happens when participants finish:
    
    - **Show Score**: Immediately or after review
    - **Show Answers**: Reveal correct answers
    - **Certificate**: Auto-generate for passing scores
    - **Notification**: Email results to participant
  </Step>
  
  <Step title="Save Assessment">
    Click **Save** to store your assessment.
  </Step>
</Steps>

## Invite Participants

<Tabs>
  <Tab title="Email Invitations">
    Send personalized invitations:
    
    1. Click **Invite Participants**
    2. Enter email addresses (one per line or comma-separated)
    3. Customize the invitation message
    4. Set deadline (optional)
    5. Click **Send Invitations**
    
    <Info>
      Each participant receives a unique link tied to their email.
    </Info>
  </Tab>
  <Tab title="Bulk Import">
    Import from CSV:
    
    ```csv
    email,name,department
    john@company.com,John Smith,Engineering
    jane@company.com,Jane Doe,Product
    ```
    
    Upload the CSV and map columns to fields.
  </Tab>
  <Tab title="Public Link">
    Create a shareable link:
    
    - Anyone with the link can take the assessment
    - Optionally require email registration
    - Set maximum attempts per email
  </Tab>
  <Tab title="LMS Integration">
    Launch via LTI from Canvas or Moodle:
    
    1. Configure LTI in your LMS
    2. Create assignment linking to assessment
    3. Students launch directly from LMS
    4. Grades sync back automatically
  </Tab>
</Tabs>

## Review Results

After participants complete the assessment:

<Steps>
  <Step title="View Summary">
    See overall statistics:
    - Average score, pass rate, completion rate
    - Score distribution histogram
    - Time taken analysis
  </Step>
  
  <Step title="Review Individual Attempts">
    For each participant:
    - Question-by-question responses
    - Time spent per question
    - Proctoring flags (if enabled)
    - Score breakdown
  </Step>
  
  <Step title="Grade Open-Ended Questions">
    For essays and short answers:
    1. View AI-suggested scores
    2. Review against rubric
    3. Adjust scores as needed
    4. Add feedback comments
  </Step>
  
  <Step title="Export Results">
    Download comprehensive reports:
    - **CSV**: Raw data for analysis
    - **PDF**: Individual score reports
    - **Summary**: Aggregate statistics
  </Step>
</Steps>

## Best Practices

<Tip>
**For effective assessments:**
- Mix question types to test different skills
- Use clear, unambiguous language
- Provide adequate time (rule of thumb: 1-2 min per MCQ)
- Test proctoring setup before sending invitations
- Include practice questions at the start
</Tip>

<Warning>
**Avoid these issues:**
- Trick questions that test reading comprehension, not knowledge
- Too many essay questions (scoring burden)
- Unrealistic time limits
- Technical jargon without context
</Warning>
