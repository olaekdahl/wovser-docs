Quizzes are perfect for live events, team building, training reinforcement, and gamified learning. Participants compete in real-time with leaderboards and instant feedback.

## Create a New Quiz

<Steps>
  <Step title="Start Quiz Creation">
    Navigate to your project and click **Create New** → **Quiz**.
  </Step>
  
  <Step title="Choose Creation Method">
    <Tabs>
      <Tab title="AI Generation">
        Enter a prompt describing your quiz:
        
        ```
        Create a 15-question quiz about cloud computing fundamentals.
        Include questions about AWS, Azure, and GCP services.
        Mix difficulty levels from beginner to intermediate.
        ```
        
        <Tip>
          Be specific about topic, difficulty, number of questions, and any specific areas to cover.
        </Tip>
      </Tab>
      <Tab title="Import from Question Bank">
        1. Click **Import from Bank**
        2. Filter by category, difficulty, or tags
        3. Select questions to add
        4. Click **Import Selected**
      </Tab>
      <Tab title="Manual Creation">
        1. Click **Add Question**
        2. Enter question text
        3. Add answer options (2-6)
        4. Mark the correct answer(s)
        5. Set time limit and points
      </Tab>
    </Tabs>
  </Step>
  
  <Step title="Edit Questions">
    Review and refine each question:
    
    | Action | Description |
    |--------|-------------|
    | ✏️ Edit | Modify question text, options, or correct answer |
    | 🔄 Regenerate | Get a new AI-generated alternative |
    | 📋 Duplicate | Create a copy to modify |
    | 🗑️ Delete | Remove the question |
    | ↕️ Reorder | Drag to change position |
  </Step>
  
  <Step title="Configure Quiz Settings">
    Customize your quiz behavior:
    
    <AccordionGroup>
      <Accordion title="Timing" icon="clock">
        - **Per-question time limit**: 10-120 seconds
        - **Auto-advance**: Move to next question automatically when time expires
        - **Show countdown**: Display timer to participants
      </Accordion>
      <Accordion title="Scoring" icon="trophy">
        - **Base points**: Points for correct answer (default: 1000)
        - **Speed bonus**: Extra points for fast answers
        - **Streak multiplier**: Bonus for consecutive correct answers
      </Accordion>
      <Accordion title="Display" icon="eye">
        - **Shuffle questions**: Randomize order for each participant
        - **Shuffle answers**: Randomize answer option order
        - **Show correct answer**: Reveal after each question or at end
      </Accordion>
      <Accordion title="Participation" icon="users">
        - **Max participants**: Limit session size (optional)
        - **Allow late join**: Let participants join after start
        - **Anonymous mode**: Hide participant names on leaderboard
      </Accordion>
    </AccordionGroup>
  </Step>
  
  <Step title="Save Quiz">
    Click **Save** to store your quiz. It's now ready to launch!
  </Step>
</Steps>

## Question Types

<CardGroup cols={2}>
  <Card title="Multiple Choice" icon="circle-dot">
    Single correct answer from 2-6 options. Most common format.
  </Card>
  <Card title="Multiple Select" icon="square-check">
    Multiple correct answers. Participants must select all correct options.
  </Card>
  <Card title="True/False" icon="toggle-on">
    Binary choice questions for quick fact-checking.
  </Card>
  <Card title="Image-Based" icon="image">
    Questions with images. Great for visual topics.
  </Card>
</CardGroup>

## Launch a Live Session

<Steps>
  <Step title="Open Your Quiz">
    From the project dashboard, click on the quiz you want to run.
  </Step>
  
  <Step title="Click Start Session">
    Click the **Start Session** button in the top right.
  </Step>
  
  <Step title="Share Join Information">
    Your session is now in the **Lobby** state. Share the join info:
    
    <CardGroup cols={3}>
      <Card title="PIN Code" icon="hashtag">
        6-digit code shown on screen
      </Card>
      <Card title="Join Link" icon="link">
        Copy and share via chat/email
      </Card>
      <Card title="QR Code" icon="qrcode">
        Scan with mobile devices
      </Card>
    </CardGroup>
  </Step>
  
  <Step title="Wait for Participants">
    Watch participants appear in the lobby. You'll see:
    - Total participant count
    - List of joined names/nicknames
    - Real-time connection status
  </Step>
  
  <Step title="Begin Quiz">
    When ready, click **Start Quiz** to begin the first question.
  </Step>
</Steps>

## Host Controls During Session

While the quiz is running, you have these controls:

| Control | Function |
|---------|----------|
| **Next Question** | Manually advance (if auto-advance is off) |
| **Pause** | Freeze the timer temporarily |
| **Skip** | Jump to next question without scoring |
| **End Session** | Stop the quiz and show final results |
| **Mute Leaderboard** | Hide standings from participants |

## After the Quiz

Once the session ends:

1. **Final Leaderboard** - Displayed to all participants
2. **Download Results** - Export CSV with all responses
3. **Question Analysis** - See which questions were hardest
4. **Share Certificates** - Send completion certificates (if enabled)

## Best Practices

<Tip>
**For engaging quizzes:**
- Keep questions under 30 seconds for fast-paced fun
- Mix easy and hard questions to keep everyone engaged
- Use images and media to add visual interest
- Test your quiz with a small group first
</Tip>

<Warning>
**Common pitfalls:**
- Questions too long to read in time limit
- Ambiguous answer options
- Too many consecutive hard questions
- Forgetting to enable late join for large events
</Warning>
