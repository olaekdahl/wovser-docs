FAQ

Frequently asked questions about Wovser.AI.

General Questions

What is Wovser.AI?

Wovser.AI is a comprehensive skills assessment platform that enables organizations to create interactive quizzes, self-paced assessments, and live coding challenges. It's designed for hiring, training, education, and certification use cases.

Who uses Wovser.AI?

  • HR Teams - Technical hiring assessments
  • Educators - Student evaluations and interactive learning
  • Training Departments - Employee skill validation
  • Certification Bodies - Credential verification

What makes Wovser.AI different?

  • AI-powered question generation - Create assessments faster
  • Live coding environments - Real terminal access in the browser
  • Enterprise integrations - SSO, SCIM, LMS support
  • Real-time competitions - Engaging quiz experiences

Account & Billing

How do I create an account?

Visit app.wovser.ai (opens in a new tab) and click Sign Up. You can register with email or use your organization's SSO.

What plans are available?

PlanBest For
FreeIndividual educators, small teams
ProGrowing organizations
EnterpriseLarge organizations, custom needs

Can I upgrade or downgrade my plan?

Yes, you can change your plan at any time from Settings → Billing. Upgrades are effective immediately; downgrades take effect at the next billing cycle.

Is there a free trial?

Yes! All paid plans include a 14-day free trial with full feature access.

Technical Questions

What browsers are supported?

We support the latest versions of:

  • Google Chrome
  • Mozilla Firefox
  • Apple Safari
  • Microsoft Edge

For code challenges, Chrome or Firefox is recommended for the best experience.

Does Wovser.AI work on mobile devices?

Yes, quizzes and assessments work on mobile devices. However, for code challenges, we recommend using a device with a full keyboard.

What programming languages are supported for code challenges?

We support 17 languages and frameworks:

Backend/General Purpose: JavaScript, TypeScript, Python, Java, Go, Rust, C++, C#, Ruby, SQL, Shell, and PowerShell.

Web Frameworks (with live preview): React, Vue, Angular, Svelte, and vanilla HTML/CSS/JS.

Web framework challenges include a live preview URL where participants can see their application running in real-time.

Is my data secure?

Yes. Wovser.AI employs:

  • Encryption at rest and in transit (TLS 1.3)
  • SOC 2 Type II compliance
  • GDPR compliance
  • Regular security audits
  • Data isolation between tenants

Using Wovser.AI

How do I join a session?

Go to app.wovser.ai/join (opens in a new tab) and enter the 6-character session code provided by your host.

Can I pause an assessment?

It depends on how the host configured the assessment. If pausing is enabled, you'll see a Pause button. Your progress is saved automatically.

What happens if I lose internet connection?

Your progress is automatically saved. Reconnect and return to the session—you'll continue from where you left off.

Can I retake an assessment?

This depends on the assessment settings. If multiple attempts are allowed, you'll see a Retake button after completion.

Hosts & Content

How do I create a quiz?

From your dashboard, click Create Quiz. Add questions manually, generate them with AI, or import from your question bank.

Can I share questions with my team?

Yes! Questions are stored in a shared question bank within your organization. Team members can access and reuse approved questions.

How does AI question generation work?

Describe your topic, select difficulty and question types, and our AI generates relevant questions. Always review AI-generated content before publishing.

Can I import existing questions?

Yes, you can import questions via:

  • CSV upload
  • Copy/paste from documents
  • API integration
  • LMS import (for supported platforms)

Integrations

Does Wovser.AI integrate with our LMS?

We support LTI 1.3 integration with:

  • Canvas
  • Moodle
  • Blackboard
  • D2L Brightspace
  • And other LTI-compatible systems

Can we use SSO?

Yes, we support:

  • SAML 2.0
  • OpenID Connect (OIDC)
  • Azure AD / Entra ID
  • Okta
  • Google Workspace
  • OneLogin

Is there an API?

Yes! Our REST API provides full platform access. See the API Reference for documentation.
