# Live Sessions

Run real-time quiz sessions with participants competing live.

import { Steps, Callout } from 'nextra/components'

## Starting a Session

<Steps>

### Select Your Quiz

From the dashboard, choose a published quiz and click **Start Session**.

### Configure Session Settings

- **Session Name** - Custom name for this instance
- **Player Limit** - Maximum participants (optional)
- **Team Mode** - Enable team competition
- **Lobby Music** - Background audio while waiting

### Open the Lobby

Click **Open Lobby** to generate a session code. Participants can join at `app.wovser.ai/join` or scan the QR code.

### Wait for Players

Monitor the lobby to see who has joined. You can:
- View participant list
- Remove players if needed
- Chat with the lobby
- Start early or wait for more players

### Launch the Quiz

Click **Start** when ready. The first question will display to all participants simultaneously.

</Steps>

## During the Session

### Host Controls

As the host, you have real-time controls:

- **Pause/Resume** - Temporarily halt the session
- **Skip Question** - Move to the next question
- **Extend Time** - Add time to current question
- **Show Leaderboard** - Display current standings
- **End Session** - Stop the session early

### Live Leaderboard

The leaderboard updates after each question:
- Top performers highlighted
- Point changes animated
- Optional: Hide leaderboard until end

<Callout type="info">
  Pro tip: Enable "leaderboard reveal" for dramatic effect—hide standings until the final question!
</Callout>

### Participant View

Players see:
- Current question and timer
- Their selected answer
- Answer confirmation
- Position changes (if leaderboard visible)

## Team Mode

Enable team competitions for collaborative learning:

### Team Setup Options

1. **Pre-assigned** - Create teams before the session
2. **Random** - Auto-assign players to balanced teams
3. **Player Choice** - Let participants form their own teams

### Team Scoring

- Individual answers contribute to team score
- Team average or total points (configurable)
- Team leaderboard displayed

## Session Features

### Question Timer

Configure timing behavior:
- **Fixed time** - Same for all questions
- **Variable** - Different time per question
- **No limit** - Wait for all answers (not recommended for live)

### Answer Reveal

After each question:
- Show correct answer
- Display answer distribution
- Brief explanation (optional)
- Quick stats

### Music & Sound Effects

Enhance engagement with:
- Lobby background music
- Countdown sounds
- Correct/incorrect audio cues
- Victory fanfare

## After the Session

### Results Screen

Display final results:
- Winner announcement
- Top 3 podium
- Final leaderboard
- Session statistics

### Post-Session Actions

- **Export Results** - Download CSV/PDF
- **Share Replay** - Generate session replay link
- **Send Certificates** - Email completion certificates
- **Schedule Follow-up** - Plan next session

### Analytics Access

After ending, review:
- Question-by-question breakdown
- Participant performance
- Engagement metrics
- Comparison to previous sessions
