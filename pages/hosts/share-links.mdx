# Share Links

Generate secure, shareable links for your assessments, quizzes, code challenges, and video assessments.

import { Callout } from 'nextra/components'

## Overview

Share Links let you distribute your content without requiring learners to have an existing account. Generate a unique token-based URL for any piece of content and share it via email, messaging apps, social media, or embed it on your website.

## Supported Content Types

| Content Type | Shareable | Anonymous Attempts |
|-------------|-----------|-------------------|
| **Quizzes** | Yes | Yes (with name entry) |
| **Assessments** | Yes | Account required |
| **Code Challenges** | Yes | Account required |
| **Video Assessments** | Yes | Account required |

## Creating a Share Link

1. Open any quiz, assessment, code challenge, or video assessment
2. Click **Share** or navigate to the **Distribute** tab
3. Click **Generate Link**
4. Optionally set an **expiration** (1–90 days)
5. Copy the generated URL

<Callout type="info">
  Share links include a secure random token. Each link is unique and can be regenerated at any time, which invalidates the previous link.
</Callout>

## Expiration

- Links can be set to expire after **1 to 90 days**
- Expired links show a friendly message directing learners to contact the host
- You can regenerate a link at any time to create a new one with a fresh expiration
- Links with no expiration set remain active indefinitely

## Anonymous Quiz Attempts

Quizzes support anonymous attempts through share links:
- Learners enter their name before starting
- They can complete the quiz and see their score
- Results are tracked and visible to the host
- No account creation required

For assessments, code challenges, and video assessments, learners are prompted to create an account or sign in when they open a share link.

## QR Codes

Share links can also be displayed as QR codes:
- Print on flyers, business cards, or presentation slides
- Display on screen during live events
- Learners scan with their phone camera to open the assessment instantly

## Tips

- **Use expiration for time-sensitive content** — Set a 7-day expiry for interview assessments
- **Regenerate for security** — If a link is shared too broadly, regenerate to invalidate the old one
- **Track engagement** — Monitor how many people access each share link from the analytics dashboard
