# Video Assessments

Evaluate candidates and learners through recorded video responses with automated transcription, keyword analysis, and scoring.

import { Callout, Steps } from 'nextra/components'

## What Are Video Assessments?

Video assessments let you ask questions that learners answer by recording short video responses. Each response is automatically transcribed using AI speech-to-text, analyzed for keyword matches, and scored based on criteria you define.

**Use cases:**
- Technical interviews and screening
- Presentation and communication skills evaluation
- Training knowledge checks
- Certification oral exams

## Creating a Video Assessment

<Steps>

### Create the Assessment

Navigate to **Video Assessments** in your dashboard and click **New Video Assessment**.

- **Title** - A clear name (e.g., "React Developer Interview")
- **Description** - What the assessment covers
- **Project** - Assign to an existing project
- **Passing Score** - Minimum percentage to pass (0-100%)

### Add Questions

From the assessment detail page, add one or more video questions:

- **Question Prompt** - The question text learners will see and answer on camera
- **Max Duration** - Recording time limit (10 seconds to 30 minutes, default 2 minutes)
- **Think Time** - Preparation countdown before recording starts (0-5 minutes, default 30 seconds)
- **Allow Retakes** - Whether learners can re-record before submitting
- **Hints** - Optional tips shown to learners before recording
- **Score Weight** - Relative importance of this question

### Configure Keyword Scoring

For each question, define **keyword categories** that the AI will look for in the learner's response.

**Keyword Categories** group related terms by topic:
- **Category Name** - e.g., "Technical Concepts", "Communication Skills"
- **Passing Match Percent** - Minimum percentage of keywords that must be mentioned

**Keywords** within each category:
- **Keyword** - The word or phrase to detect (e.g., "virtual DOM")
- **Synonyms** - Alternative forms (e.g., "v-DOM", "virtual document object model")
- **Weight** - Importance of this keyword
- **Critical** - If marked critical, it must be mentioned to pass

### Publish

Once you've added questions and configured keywords, click **Publish** to make the assessment active. Learners can now be invited.

</Steps>

<Callout type="info">
  Questions and keywords cannot be edited after publishing. Make sure your keyword configuration is complete before going live.
</Callout>

## How Scoring Works

When a learner submits a video response, the system automatically:

1. **Transcribes** the audio using AI speech-to-text (OpenAI Whisper)
2. **Matches keywords** in the transcript against your defined keywords and synonyms
3. **Calculates a score** per category based on matched keyword weights
4. **Determines pass/fail** based on your passing score threshold and critical keywords

| Scoring Factor | How It Works |
|----------------|-------------|
| Keyword matches | Each matched keyword contributes its weight to the category score |
| Category score | `(matched weight / total weight) * 100` |
| Critical keywords | All critical keywords must be found, or the category fails |
| Overall score | Average of all category scores |
| Pass/Fail | Overall score must meet the passing threshold |

## Inviting Learners

From the **Distribute** tab on your assessment:

- **Email Invites** - Send individual or bulk email invitations
- **Share Link** - Generate a public link learners can use
- **QR Code** - Display or print a scannable QR code

You can track invitation status (Pending, In Progress, Completed) from the same tab.

## Reviewing Submissions

The **Submissions** tab shows all learner responses. Click any submission to open the review page, which includes:

- **Video Playback** - Watch the recorded response with play/pause controls
- **Full Transcript** - AI-generated text of what was said
- **Keyword Analysis** - Which keywords were found, how many times, and at what timestamps
- **Category Breakdown** - Score per keyword category with pass/fail status
- **Overall Score** - Automatically calculated percentage
- **Speaking Analytics** - Speaking pace, pause count, filler words, and sentiment

### Manual Review

You can override the automated result:
- **Mark as Pass** or **Fail** manually
- **Reprocess** a submission if the initial analysis failed
- **Delete** a submission to remove it entirely

<Callout type="warning">
  Reprocessing requires the original video to still be available in storage. Processing typically takes 30-60 seconds per video.
</Callout>

## Assessment Lifecycle

| Status | Description |
|--------|-------------|
| **Draft** | Building phase. Add questions, configure keywords, adjust settings. |
| **Active** | Live and accepting submissions. Invite learners and review results. |
| **Archived** | Closed. No new submissions accepted. Results remain viewable. |

## Visibility Settings

Control what learners see after completing the assessment:

- **Show Results** - Learners can view their score and pass/fail status
- **Show Transcript** - Learners can read their own transcript and keyword matches

## Tips for Effective Video Assessments

- **Keep questions focused** - One clear question per video prompt
- **Use generous think time** - 30-60 seconds helps learners organize their thoughts
- **Define synonyms liberally** - Learners may use different terminology than expected
- **Mark only essential keywords as critical** - Too many critical keywords leads to false failures
- **Test with a colleague** - Submit a test response before sending to real candidates
