# Quickstart

Get started with Wovser.AI in under 5 minutes.

import { Steps, Callout } from 'nextra/components'

## Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- An email address for account creation

## Quick Setup

<Steps>

### Create Your Account

Join the Wovser.AI waitlist at [www.wovser.ai](https://www.wovser.ai) and be among the first to try it.

### Set Up Your Organization

After signing in, you'll be prompted to create or join an organization. As an admin, you can:
- Set your organization name and branding
- Configure default settings
- Invite team members

### Create Your First Quiz

Navigate to the **Dashboard** and click **Create Quiz**. You can:
- Add questions manually
- Use AI to generate questions
- Import from existing question banks

### Host a Live Session

Once your quiz is ready, click **Start Session** to begin. Share the session code with participants so they can join.

### Review Results

After the session ends, view the **Analytics** tab to see:
- Individual and group performance
- Question difficulty analysis
- Areas for improvement

</Steps>
