# Learner Management

Invite, track, and manage learners across your organization's projects and assessments.

import { Callout, Steps } from 'nextra/components'

## Overview

The Learner Management system gives creators full control over the learner lifecycle — from initial invitation through assessment completion and certification. Manage learners individually or in bulk, track their progress across projects, and generate reports.

## Inviting Learners

### Single Invite

<Steps>

### Open Project

Navigate to the project where you want to add learners.

### Click Invite Learner

Enter the learner's email and optionally their name. Select which assessments and code challenges to assign immediately.

### Send Invitation

The learner receives an email with a link to create their account and access assigned content.

</Steps>

### Bulk Upload

For large groups, use CSV or Excel upload:

1. Click **Bulk Invite** in your project's learner list
2. Upload a CSV or Excel file with columns for email, name, etc.
3. Preview the import and resolve any issues (duplicates, invalid emails)
4. Choose whether to send invitation emails immediately
5. Click **Import** to add all learners at once

<Callout type="info">
  CSV and Excel files must be under 5MB. The system accepts `.csv`, `.xlsx`, and `.xls` formats.
</Callout>

## Learner Dashboard

Each learner has a profile showing:

- **Assigned assessments** — What they need to complete
- **Submissions** — Their attempts and scores
- **Progress** — Completion status across all assigned content
- **Certificates** — Earned certificates and badges
- **Project membership** — Which projects they belong to

## Project-Scoped Learners

Learners are organized by project. A single learner can belong to multiple projects with different assignments in each:

- **Project A** — Assigned JavaScript quiz + React code challenge
- **Project B** — Assigned system design assessment + video interview

This allows you to create distinct learning paths or hiring pipelines within the same organization.

## Tracking Progress

The learner list provides at-a-glance progress tracking:

| Status | Meaning |
|--------|---------|
| **Invited** | Invitation sent, not yet started |
| **In Progress** | Learner has started at least one assignment |
| **Completed** | All assigned content has been submitted |
| **Passed** | Met passing thresholds on all assignments |

### Filters and Search

- **Search** by name or email
- **Filter** by project, status, or date range
- **Sort** by name, progress, score, or last activity

## Actions

| Action | Description |
|--------|-------------|
| **Assign Content** | Add new assessments or challenges to a learner |
| **Remove from Project** | Revoke access to a specific project |
| **View Submissions** | See all their attempts across all content |
| **Export** | Download learner data as CSV |

## Tips

- **Use projects to organize** — Group learners by cohort, department, or role
- **Bulk upload for efficiency** — Import hundreds of learners from a spreadsheet
- **Track regularly** — Check the progress dashboard weekly to identify learners who may need follow-up
- **Combine with certificates** — Set up automatic certification for learners who pass all required assessments
