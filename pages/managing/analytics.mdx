# Analytics

Understand performance patterns and improve your assessments with detailed analytics.

import { Callout } from 'nextra/components'

## Dashboard Overview

The analytics dashboard provides at-a-glance insights:

- **Sessions This Month** - Activity summary
- **Average Score** - Overall performance trend
- **Completion Rate** - Participant engagement
- **Top Performers** - Leading participants

## Session Analytics

### Performance Metrics

After each session, view:

| Metric | Description |
|--------|-------------|
| Average Score | Mean score across all participants |
| Median Score | Middle score (less affected by outliers) |
| Score Range | Highest to lowest scores |
| Standard Deviation | Score distribution spread |
| Pass Rate | Percentage meeting threshold |

### Question Analysis

For each question, see:
- **Difficulty Index** - Percentage who answered correctly
- **Discrimination Index** - How well it differentiates skill levels
- **Average Time** - How long participants spent
- **Answer Distribution** - Which options were selected

<Callout type="info">
  Questions with low discrimination indices may need revision—they don't effectively separate high and low performers.
</Callout>

### Time Analysis

Understand pacing:
- Average completion time
- Time per question breakdown
- Early finishers vs time-limit hits
- Rush patterns (final minutes behavior)

## Participant Reports

### Individual Performance

For each participant:
- Overall score and percentile
- Section-by-section breakdown
- Correct/incorrect question list
- Time spent per question
- Comparison to group average

### Progress Tracking

Track improvement over time:
- Historical performance chart
- Skill area progression
- Streak and consistency metrics
- Personal best highlights

## Aggregate Analytics

### Cohort Comparison

Compare groups:
- By department or team
- By time period
- By assessment type
- By training completion

### Trend Analysis

Identify patterns:
- Score trends over time
- Seasonal variations
- Post-training improvements
- Skill gaps by topic

## Using Analytics Effectively

### Improving Assessments

1. Review questions with very high or low difficulty
2. Check for misleading answer options
3. Validate time allocations
4. Update content based on feedback

### Identifying Training Needs

- Spot consistent weak areas across participants
- Compare pre/post training results
- Track certification readiness
- Plan targeted interventions

### Benchmarking

- Establish baseline scores for roles
- Compare candidates to benchmarks
- Track organizational skill levels
- Measure training program ROI
