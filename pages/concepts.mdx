# Core Concepts

Understanding the key concepts in Wovser.AI will help you get the most out of the platform.

## Organizations & Tenants

Wovser.AI is a multi-tenant platform. Each **organization** (tenant) has its own:
- User accounts and roles
- Question banks and content
- Branding and customization
- Usage quotas and billing

## User Roles

import { Callout } from 'nextra/components'

Wovser.AI uses four roles to control access within an organization:

| Role | Description |
|------|------------|
| **Owner** | Full access to everything — billing, settings, member management, and content. Every organization has at least one Owner. |
| **Admin** | Manage content, projects, settings, and integrations. Cannot access billing or modify Owners. |
| **Member** | Create and manage content within assigned projects. Cannot access organization settings. |
| **Learner** | Take assessments and view own results. No creation or management access. |

<Callout type="info">
  See [Team Management](/hosts/team-management) for details on inviting members and managing roles.
</Callout>

## Content Types

### Quizzes
Live, competitive sessions where participants answer questions in real-time. Features include:
- Multiple choice, true/false, and short answer questions
- Time limits per question
- Live leaderboards
- Team mode support

### Assessments
Self-paced evaluations for measuring skills. Features include:
- Flexible time limits
- Multiple attempts (configurable)
- Automated scoring
- Detailed feedback

### Video Assessments
Recorded video responses evaluated with AI. Features include:
- Questions answered on camera with configurable time limits
- AI-powered transcription (speech-to-text)
- Keyword and topic matching with synonym support
- Speaking analytics (pace, filler words, sentiment)
- Automated scoring with manual review option

### Code Challenges
Programming tasks completed in browser-based coding environments. Features include:
- **17+ supported languages**: JavaScript, TypeScript, Python, Java, Go, Rust, C++, C#, Ruby, Lua, SQL, Shell, PowerShell
- **Web frameworks with live preview**: React, Vue, Angular, Svelte, and vanilla HTML/CSS/JS
- Real terminal access via VS Code in the browser
- Test case validation
- Workspace persistence

### Certificates & Badges
Recognize achievements with professional credentials. Features include:
- Five template layouts (Classic, Modern, Minimal, Professional, Academic)
- Custom branding with colors, logos, and signatures
- Digital badges in five shapes (Circle, Shield, Hexagon, Square, Ribbon)
- QR code verification links
- One-click LinkedIn sharing
- PDF download

## Execution Technologies

<Callout type="info">
  Wovser.AI uses multiple execution technologies to provide the best experience for each language.
</Callout>

### WASM (WebAssembly)
Code runs directly in the browser using WebAssembly runtimes:
- **Instant execution** - No server round-trip needed
- **Languages**: Python (Pyodide), JavaScript/TypeScript (QuickJS + esbuild), Ruby (ruby.wasm), Lua (Wasmoon)
- **Use case**: Algorithm challenges, single-file exercises

### WebContainers
Full Node.js runtime in the browser (by StackBlitz):
- **npm packages** - Install and use any npm package
- **Multi-file projects** - Full file system support
- **Frameworks**: React, Vue, Angular, Svelte, Node.js
- **Use case**: Full-stack projects, framework exercises

### Sandpack
CodeSandbox's browser-based runtime:
- **Live preview** - See changes instantly
- **Console output** - Debug JavaScript in the browser
- **Use case**: HTML/CSS/JavaScript fundamentals

### Cloud Execution
Kubernetes-based containers for advanced languages:
- **Full toolchains** - Compilers, package managers, debuggers
- **Languages**: Java, Go, Rust, C++, C#
- **Use case**: Complex build requirements, large projects

## Sessions & Participation

<Callout type="info">
  A **session** is an instance of a quiz or assessment that players can join.
</Callout>

### Session Codes
Each session has a unique 6-character code that players use to join. Codes are:
- Case-insensitive
- Valid for the session duration
- Shareable via link or QR code

### Session States
- **Lobby** - Waiting for players to join
- **Active** - Questions are being presented
- **Paused** - Temporarily halted by host
- **Completed** - Session has ended

## Question Bank

Questions are stored in a centralized **question bank** that can be:
- Organized into categories and tags
- Reused across multiple quizzes
- Shared within your organization
- Enhanced with AI-generated content

## Scoring & Analytics

### Scoring Methods
- **Points-based** - Each correct answer earns points
- **Speed bonus** - Faster answers earn more points
- **Partial credit** - Available for certain question types

### Analytics
After sessions, you can view:
- Individual performance reports
- Question difficulty analysis
- Response time distributions
- Trend analysis over time
