## Integration Categories

### Learning Management Systems (LMS)

Connect to your LMS for seamless learning experiences:
- **LTI 1.3** - Industry-standard integration protocol
- **Grade Passback** - Automatic score synchronization
- **Deep Linking** - Embed assessments directly in courses
- **Roster Sync** - Import students and instructors

<Callout type="info">
  LTI integrations allow students to access Wovser.AI assessments without leaving their LMS.
</Callout>

### Single Sign-On (SSO)

Enable SSO for seamless authentication:
- **SAML 2.0** - Enterprise standard
- **OIDC** - Modern OAuth-based SSO
- **JIT Provisioning** - Create users on first login

### User Provisioning

Automate user management:
- **SCIM 2.0** - Automatic user/group sync
- **Directory Integration** - Azure AD, Okta, OneLogin

### Developer Tools

Build custom integrations:
- **REST API** - Full platform access
- **Webhooks** - Real-time event notifications
- **Embeddable Widgets** - White-label components
