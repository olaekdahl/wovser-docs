# Joining Sessions

Learn how to join live quizzes and assessment sessions.

import { Steps, Callout, Tabs } from 'nextra/components'

## Join Methods

<Tabs items={['Session Code', 'Direct Link', 'QR Code']}>
  <Tabs.Tab>
    1. Go to `app.wovser.ai/join`
    2. Enter the 6-character session code
    3. Click **Join**
    4. Enter your name (if not logged in)
  </Tabs.Tab>
  <Tabs.Tab>
    1. Click the link shared by your host
    2. You'll be taken directly to the session
    3. Log in or enter your name
    4. Wait in the lobby
  </Tabs.Tab>
  <Tabs.Tab>
    1. Open your phone's camera
    2. Point at the QR code
    3. Tap the link that appears
    4. Join from your mobile device
  </Tabs.Tab>
</Tabs>

## Before You Join

### System Requirements

- **Browser** - Chrome, Firefox, Safari, or Edge (latest versions)
- **Internet** - Stable connection (minimum 1 Mbps)
- **Device** - Computer, tablet, or smartphone

### Recommended Setup

For the best experience:
- Use a computer with a keyboard
- Close unnecessary browser tabs
- Disable browser extensions that might interfere
- Ensure your device is charged or plugged in

<Callout type="warning">
  For code challenges, a full keyboard is strongly recommended. Mobile devices may limit your coding speed.
</Callout>

## The Lobby Experience

### What Happens in the Lobby

After joining, you'll wait in the lobby until the host starts the session:
- See other participants who have joined
- View the session name and description
- Check the expected duration
- Review any instructions

### While Waiting

- **Stay on the page** - Don't navigate away
- **Keep sound on** - You'll hear when the session starts
- **Be ready** - The first question may appear quickly

## Troubleshooting

### Can't Join?

<Steps>

### Check the Code

Ensure you've entered the code correctly. Codes are not case-sensitive but must be exact.

### Verify Session Status

The session might not be open yet, or it may have already ended.

### Try a Different Browser

Some browser extensions or settings can interfere. Try incognito mode.

### Contact Your Host

If problems persist, reach out to the person who invited you.

</Steps>

### Connection Issues

If you lose connection during a session:
- Your progress is automatically saved
- Rejoin using the same code
- You'll return to where you left off
