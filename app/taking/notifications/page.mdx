# Notifications

Stay informed about new assignments, results, and updates.

import { Callout } from 'nextra/components'

## Overview

Wovser.AI keeps you up to date with a built-in notification system. Receive alerts when you're assigned new assessments, when results are released, or when you receive a message.

## Notification Types

| Notification | Description |
|-------------|-------------|
| **New Assignment** | You've been assigned a new assessment, quiz, or code challenge |
| **Results Available** | Your scores or feedback have been released |
| **Certificate Earned** | You've passed an assessment and earned a certificate |
| **Session Invitation** | You've been invited to a live quiz session |
| **Reminder** | An upcoming assessment deadline is approaching |

## Where Notifications Appear

### In-App
- **Bell icon** in the navigation bar shows your unread count
- Click to see a dropdown of recent notifications
- Click any notification to go directly to the relevant content

### Push Notifications (Mobile)
If you're using the Wovser.AI mobile app, you'll receive push notifications on your device for important events like new assignments and released results.

<Callout type="info">
  You can manage push notification preferences in the mobile app's settings.
</Callout>

## Managing Notifications

- **Mark as read** — Click the checkmark on individual notifications
- **Mark all as read** — Clear all unread notifications at once
- Notifications are paginated — scroll down to load older ones

## Tips

- **Check regularly** — Don't miss assignment deadlines
- **Enable push notifications** — Get instant alerts on your phone
- **Clear old notifications** — Mark read to keep your inbox clean
