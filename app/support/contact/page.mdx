## How to Submit a Request

### What to Include

For the fastest resolution, include:

- **Account email** - The email associated with your account
- **Organization name** - Your company or institution
- **Description** - Clear explanation of the issue
- **Steps to reproduce** - How can we see the problem?
- **Screenshots/recordings** - Visual evidence helps
- **Error messages** - Exact text of any errors
- **Browser & OS** - e.g., Chrome 120 on Windows 11

### For Session Issues

Also include:
- Session code
- Approximate time of the issue
- Number of affected participants

### For Integration Issues

Also include:
- Integration type (SSO, SCIM, LTI)
- Configuration details (with sensitive info redacted)
- Error logs if available
