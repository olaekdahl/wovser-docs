## What is Wovser.AI?

Wovser.AI is a comprehensive skills orchestration platform that enables organizations to create, deliver, and analyze quizzes, structured assessments, and live coding challenges—all enhanced by AI.

## Key Features

<Steps>
  <Step title="AI-Powered Content Generation">
    Generate quizzes, assessment questions, and coding challenges from simple prompts using GPT-4.
  </Step>
  <Step title="Live Multiplayer Sessions">
    Host real-time quiz competitions with PIN-based join codes and live leaderboards.
  </Step>
  <Step title="Secure Code Execution">
    Evaluate code submissions in isolated VS Code workspaces supporting 10+ programming languages.
  </Step>
  <Step title="AI Proctoring">
    Ensure assessment integrity with webcam monitoring and behavioral analysis (optional).
  </Step>
  <Step title="Enterprise Integrations">
    Connect with Canvas, Moodle, Workday, Greenhouse, and more via LTI, SCIM, and webhooks.
  </Step>
</Steps>
