    - 7 days to evaluate
    - No credit card required

    - Shell, PowerShell
    - SQL

</AccordionGroup>

## Quizzes & Assessments

<AccordionGroup>
  <Accordion title="How does AI question generation work?">
    Enter a prompt describing your topic, difficulty, and number of questions. Our AI (powered by GPT-4) generates relevant questions with answer options. You can edit, regenerate, or manually add questions.
  </Accordion>
  
  <Accordion title="Can I import existing questions?">
    Yes! You can:
    - Import from our question bank
    - Upload via CSV
    - Copy/paste from other sources
    - Use the API for bulk import
  </Accordion>
  
  <Accordion title="How many participants can join a session?">
    | Plan | Max Participants |
    |------|------------------|
    | Pro | 200 per session |
    | Scale | 500 per session |
    | Enterprise | Unlimited |
  </Accordion>
  
  <Accordion title="Can participants join late?">
    If enabled by the host, participants can join after a session starts. They'll join from the current question but may miss earlier questions.
  </Accordion>
</AccordionGroup>

## Code Challenges

<AccordionGroup>
  <Accordion title="How are code challenges executed?">
    Each participant gets an isolated VS Code workspace in the cloud. Code runs in secure containers with:
    - No network access (by default)
    - Resource limits (CPU, memory, time)
    - Pre-installed language runtimes
  </Accordion>
  
  <Accordion title="Can candidates install packages?">
    By default, no. Workspaces come with standard libraries pre-installed. Custom dependencies can be configured for Enterprise plans.
  </Accordion>
  
  <Accordion title="How is code scored?">
    - **Test cases**: Pass/fail against predefined tests
    - **Hidden tests**: Prevent hardcoding answers
    - **AI review**: Optional code quality feedback
  </Accordion>
  
  <Accordion title="What if a candidate's code times out?">
    If code exceeds the time limit (default 10s), execution stops and the test fails. Candidates should optimize their solutions for efficiency.
  </Accordion>
</AccordionGroup>

## Proctoring

<AccordionGroup>
  <Accordion title="What does proctoring monitor?">
    When enabled, proctoring can track:
    - Webcam (face detection, person count)
    - Tab/window switching
    - Copy/paste activity
    - Browser focus
  </Accordion>
  
  <Accordion title="Does proctoring auto-fail candidates?">
    No. Proctoring flags suspicious activity for review. A human reviewer (you) decides whether the behavior warrants action.
  </Accordion>
  
  <Accordion title="Is proctoring required?">
    No. Proctoring is optional and must be explicitly enabled by the host. Participants must consent before starting.
  </Accordion>
  
  <Accordion title="What data is stored?">
    - Event logs (timestamps, event types)
    - Flagged frame thumbnails (if faces detected)
    - Risk scores
    
    Data is retained per your tenant's retention policy.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="I can't join a session">
    - Verify the PIN code is correct
    - Check if the session has started (late join may be disabled)
    - Try a different browser
    - Clear cache and cookies
  </Accordion>
  
  <Accordion title="My code won't run">
    - Check for syntax errors
    - Verify you're using the correct language
    - Ensure you haven't exceeded resource limits
    - Check the terminal for error messages
  </Accordion>
  
  <Accordion title="Camera won't work for proctoring">
    - Grant camera permissions in browser settings
    - Close other apps using the camera
    - Try a different browser
    - Check if your camera works in other apps
  </Accordion>
</AccordionGroup>
