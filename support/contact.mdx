## Submit a Support Request

<Info>
For faster resolution, include as much detail as possible.
</Info>

When contacting support, please provide:

### Required Information

- **Your email** - Account email address
- **Issue description** - What's happening?
- **Expected behavior** - What should happen?
- **Steps to reproduce** - How can we see the issue?

### Helpful Additions

- **Session/Quiz ID** - Found in the URL
- **Browser & version** - e.g., Chrome 120
- **Screenshots** - Visual evidence of the issue
- **Error messages** - Copy full error text
- **Console logs** - Press F12 → Console tab

## Issue Categories

### Account & Billing

- Login problems
- Password reset
- Plan upgrades/downgrades
- Invoice requests
- Cancellation

### Technical Issues

- Session won't start
- Questions not loading
- Scores not calculating
- Integration problems
- API errors
